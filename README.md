# Academic Website

A simple static academic website built with HTML, CSS, and JavaScript.

## Pages
- Home / About
- Research
- Publications
- CV
- Notes

## Structure
- `index.html` — homepage
- `research.html` — research overview
- `publications.html` — publications and outputs
- `cv.html` — CV page
- `blog.html` — notes/blog page
- `css/style.css` — shared styling
- `js/main.js` — navigation, search, back-to-top button
- `assets/images/` — images
- `assets/docs/` — CV PDF and other documents
